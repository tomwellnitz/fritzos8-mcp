# Tool-Referenz

<!-- generiert von scripts/gen_tool_reference.py – nicht von Hand bearbeiten -->

159 Tools. Jedes Tool hat den optionalen Parameter `box` (Mehrbox-Betrieb, Namen in `server_status`); er ist unten nicht aufgeführt. `?` = optionaler Parameter. Spalte „Recht“: das nötige Recht des FRITZ!Box-Benutzers (System > FRITZ!Box-Benutzer); „FRITZ!Box Einstellungen“ schließt das App-Recht ein. `setup_check` zeigt, welche Rechte der eingerichtete Benutzer hat und welche Tools deshalb fehlen.

Rechte: **settings** = FRITZ!Box Einstellungen; **app** = Eingeschränkte FRITZ!Box Einstellungen für Apps; **phone** = Sprachnachrichten, Faxnachrichten, FRITZ!App Fon und Anrufliste; **dial** = Wählhilfe; **nas** = Zugang zu NAS-Inhalten; **smarthome** = Smart Home; **–** = kein Recht nötig.
