# Support

fritzos8-mcp is a spare-time open-source project maintained by one person. Please help keep support efficient:

| You want to …                                   | Go to                                                                                              |
|-------------------------------------------------|----------------------------------------------------------------------------------------------------|
| ask how to set something up or use a tool       | [GitHub Discussions → Q&A](https://github.com/tomwellnitz/fritzos8-mcp/discussions/categories/q-a) |
| report a bug                                    | [bug report](https://github.com/tomwellnitz/fritzos8-mcp/issues/new?template=bug_report.yml)        |
| report that it works (or not) on your box model | [compatibility report](https://github.com/tomwellnitz/fritzos8-mcp/issues/new?template=compatibility.yml) |
| propose a new tool or improvement               | [feature request](https://github.com/tomwellnitz/fritzos8-mcp/issues/new?template=feature_request.yml) |
| report a security vulnerability                 | **privately**, see [SECURITY.md](SECURITY.md) – never in a public issue                             |

Before asking, please check:

1. the [README](README.md) (quick start, configuration, permissions) and the [tool reference](docs/TOOLS.md),
2. `setup_check` – the tool tells you which box rights are missing and which tools will not work,
3. [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md) for known model/firmware differences,
4. existing [issues](https://github.com/tomwellnitz/fritzos8-mcp/issues?q=is%3Aissue) and discussions.

**Never post** passwords, session IDs, Wi-Fi keys, tokens, serial numbers, MAC or IP addresses, device names or phone
numbers. Anonymize box output with `fritzos8-anonymize` first (see [docs/fixtures.md](docs/fixtures.md)).

Questions about FRITZ!OS itself (not about this server) are best asked in the FRITZ! support channels. This project is
not affiliated with FRITZ! GmbH (formerly AVM).

Issues and discussions are welcome in English or German.
